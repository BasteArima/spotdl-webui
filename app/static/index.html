Апгрейд качества до 320k
Постепенно заменяет треки библиотеки (YouTube/Deezer) на 320k со Spotify. Идёт медленно (безопасный режим, паузы между загрузками), переживает рестарт и не качает повторно уже улучшенные. Можно остановить в любой момент.
Доступ
Navidrome
После синка, загрузок и апгрейда webui попросит Navidrome пересканировать библиотеку — новые треки появятся сразу, а не по его расписанию. Скан запускается, когда очередь затихнет (пачка загрузок = один скан). Нужен пользователь-администратор Navidrome.
мин
YouTube cookies
Без cookies YouTube на объёме начинает требовать «подтвердите, что вы не робот». Экспортируйте cookies youtube.com в формате Netscape (расширение вроде «Get cookies.txt LOCALLY») и загрузите файл сюда.
Deezer (фолбэк для треков, которых нет на YouTube)
Нужен ARL — значение cookie arl на deezer.com после входа. Это секрет уровня пароля: хранится в /conf/deezer_arl.txt с правами 600, обратно в браузер не отдаётся.
Spotify напрямую (librespot, 320k)
Вход под вашим аккаунтом Spotify для кнопки «Spotify 320k» и апгрейда библиотеки (320k — с Premium). Можно входить через Facebook. Креды хранятся в /conf/zotify_credentials.json с правами 600.
  1. Откройте страницу входа Spotify ↗, войдите (можно через Facebook) и разрешите доступ.
  2. Браузер откроет 127.0.0.1:5588/login?code=… — страница не загрузится, это нормально. Скопируйте адрес из адресной строки и вставьте сюда:
Spotify-приложение (для Liked Songs)
Нужно, чтобы синхронизировать «Любимые треки» (плейлист со ссылкой saved). Создайте приложение на developer.spotify.com: Redirect URI http://127.0.0.1:9900/, API — Web API. Client ID и secret — в Settings приложения.
Вход в Spotify
  1. Откройте страницу входа Spotify ↗, войдите (можно через Facebook) и разрешите доступ.
  2. Браузер откроет 127.0.0.1:9900/?code=… — страница не загрузится, это нормально. Скопируйте адрес из адресной строки и вставьте сюда:
Системные (только env / compose)
Меняются в compose и применяются после пересоздания контейнера.
