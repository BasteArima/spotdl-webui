# spotdl web-ui

Веб-интерфейс для музыкальной библиотеки, которую скачивает [spotdl](https://github.com/spotDL/spotify-downloader)
по плейлистам Spotify и раздаёт [Navidrome](https://www.navidrome.org/). Один Docker-контейнер:
синхронизирует плейлисты по расписанию, а главное — помогает **добить треки, которые spotdl
не нашёл на YouTube**, из других источников.

## Что умеет

- **Плейлисты** — плейлисты Spotify (и «Любимые треки»), синхронизация вручную и по
  расписанию. Треки ложатся в библиотеку, m3u-плейлисты — рядом, Navidrome их подхватывает.
- **Индекс библиотеки** — сервис сам знает, какие файлы лежат в `/music`, из каких плейлистов
  они пришли и чего не хватает. Индекс обновляется после каждого синка и загрузки.
- **Недокачанные треки** — всё, что spotdl не нашёл или не смог скачать, собрано в одном месте,
  по плейлистам. Источник выбирается на трек или сразу на все:
  - **Авто** — сначала Deezer по ISRC, потом Spotify напрямую;
  - **Deezer** — точное совпадение по ISRC;
  - **Spotify 320k** — прямо из Spotify через ваш аккаунт;
  - **своя ссылка YouTube / YT Music**, которую вы нашли сами;
  - **свой файл** — метаданные и обложка подтянутся со Spotify.
- **Дубли** — один и тот же трек, пришедший разными путями: по общему ID, ISRC или названию,
  исполнителю и длительности. Оба варианта можно прослушать прямо на странице и решить,
  одно это или разное. Ремастер, live, кавер и «Russian ver.» — разные треки.
- **Улучшение до 320k** — фоновая замена треков библиотеки на 320k со Spotify: медленно,
  с паузами и лимитом в сутки, переживает рестарт.
- **Пересканирование Navidrome** после синка и загрузок — новые треки видны сразу.
- **Всё настраивается в браузере** — раздел «Настройки», compose почти пустой.
- **Строка «что сейчас происходит»** в каждом разделе: синк с прогрессом «312 из 806» и текущим
  треком, загрузки, улучшение — или «всё спокойно» и когда следующий автосинк.
- «Активность» с понятной историей и логами по нажатию, вход по паролю (или без него в
  закрытой сети), светлая/тёмная тема, удобно с телефона (нижние вкладки).

## Быстрый старт

Нужны Docker (удобно — Portainer) и папки для данных и музыки. Стек:

```yaml
services:
  music-webui:
    image: ghcr.io/bastearima/spotdl-webui:latest
    container_name: spotdl-webui
    restart: unless-stopped
    mem_limit: 2g
    memswap_limit: 2g
    cpus: 2.0
    ports:
      - "4535:8000"
    environment:
      - PUID=998      # uid:gid, под которым Navidrome читает музыку
      - PGID=100
    volumes:
      - "/путь/к/данным/spotdl:/conf"
      - "/путь/к/музыке:/music"
```

Откройте `http://<сервер>:4535` — сервис попросит **придумать пароль**. Откройте UI сразу после
запуска: пока пароль не задан, его может задать первый, кто зайдёт. Если порт виден из
интернета, задайте пароль заранее через `APP_PASSWORD` (см. [настройки](docs/configuration.md#вход-и-пароль)).

Подробно: сборка своего образа, права на папки, обновление, переезд со старого контейнера
автосинка — в [docs/installation.md](docs/installation.md).

## Первая настройка

Всё — во вкладке **«Настройки»**. Обязательного почти ничего нет:

1. **YouTube cookies** — загрузите `cookies.txt`, иначе на объёме YouTube начнёт требовать
   «подтвердите, что вы не робот». [Как получить](docs/sources.md#youtube-и-cookies)
2. **Navidrome** — адрес и админ-пользователь, чтобы новые треки появлялись сразу.
   [Подробнее](docs/sources.md#navidrome)
3. По желанию — источники для треков, которых нет на YouTube:
   [Spotify напрямую](docs/sources.md#spotify-напрямую-librespot) (вход через ваш аккаунт) и
   [Deezer](docs/sources.md#deezer) (ARL-токен).
4. По желанию — [Liked Songs](docs/sources.md#liked-songs): нужно своё приложение Spotify.

Баннер вверху страницы подскажет, если чего-то не хватает.

## Как пользоваться

Разделы — в меню слева (на телефоне — вкладки внизу и «Ещё»):

1. **Главная** — что происходит сейчас, состояние источников, что требует решения и что
   недавно добавилось.
2. **Плейлисты** → «Добавить»: имя и ссылка на плейлист / альбом / исполнителя Spotify (или
   `saved` для «Любимых треков») → **Синхронизировать**. Дальше их обновляет автосинк (по
   умолчанию раз в сутки). На странице плейлиста — его треки и недокачанные с выбором источника.
3. **Внимание** — то, что сервис не может решить сам:
   - **Не скачано** — треки без файла, по плейлистам. Выберите источник для трека или для всех
     сразу; для своей ссылки «искать на YouTube» откроет поиск.
   - **Дубли** — «уверенные» можно подтвердить пачкой, «под вопросом» — послушать и решить.
   - **Источники** — плейлисты, которые площадка больше не отдаёт (удалены или закрыты).
4. **Библиотека** — что лежит в `/music`: треки, альбомы, исполнители, поиск и фильтр по источнику.
5. **Качество 320k** — старт/стоп фонового улучшения, прогресс, оценка времени и последние треки.
6. **Активность** — история задач и подробный лог по нажатию; идущие задачи можно отменить.
7. **Настройки** — источники, синхронизация, Navidrome, доступ.

Скачанный трек сам попадает в m3u-плейлист и исчезает из недокачанных.

Прежний интерфейс пока доступен по адресу `/legacy` (ссылка — в «Настройки» → «О системе»).
Адрес `/new`, где новый интерфейс жил во время переезда, ведёт на главную.

## Риски

Скачивание через librespot («Spotify 320k», апгрейд) и с Deezer нарушает условия этих сервисов:
**аккаунт могут заблокировать**, особенно при массовых загрузках. Безопасный режим, паузы и
лимит в сутки снижают риск, но не убирают его. Используйте для личной библиотеки и на свой риск.
