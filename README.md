# spotdl web-ui

Веб-интерфейс для музыкальной библиотеки, которую скачивает [spotdl](https://github.com/spotDL/spotify-downloader)
по плейлистам Spotify и раздаёт [Navidrome](https://www.navidrome.org/). Один Docker-контейнер:
синхронизирует плейлисты по расписанию, а главное — помогает **добить треки, которые spotdl
не нашёл на YouTube**, из других источников.

## Что умеет

- **Плейлисты** — список плейлистов Spotify (и «Любимые треки»), синхронизация вручную и по
  расписанию. Треки ложатся в библиотеку, m3u-плейлисты — рядом, Navidrome их подхватывает.
- **Ненайденные треки** — всё, что spotdl не нашёл, собрано в одном месте. Для каждого трека:
  - **Скачать** по ссылке YouTube / YT Music, которую вы нашли сами;
  - **Deezer** — точное совпадение по ISRC;
  - **Spotify 320k** — прямо из Spotify через ваш аккаунт;
  - **📁 Файл** — залить свой файл: метаданные и обложка подтянутся со Spotify.
- **Апгрейд до 320k** — фоновая замена треков библиотеки на 320k со Spotify: медленно,
  с паузами и лимитом в сутки, переживает рестарт.
- **Пересканирование Navidrome** после синка и загрузок — новые треки видны сразу.
- **Всё настраивается в браузере** — вкладка «Настройки», compose почти пустой.
- Очередь задач с логами и отменой, вход по паролю (или без него в закрытой сети),
  тёмная/светлая тема, работает с телефона.

## Быстрый старт

Нужны Docker (удобно — Portainer) и папки для данных и музыки. Стек:

```yaml
services:
  music-webui:
    image: ghcr.io/bastearima/spotdl-webui:latest
    container_name: spotdl-webui
    restart: unless-stopped
    mem_limit: 1g
    cpus: 2.0
    ports:
      - "4535:8000"
    environment:
      - PUID=998      # uid:gid, под которым Navidrome читает музыку
      - PGID=100
    volumes:
      - "/путь/к/данным/spotdl:/conf"
      - "/путь/к/музыке:/music"
```

Откройте `http://<сервер>:4535` — сервис попросит **придумать пароль**. Откройте UI сразу после
запуска: пока пароль не задан, его может задать первый, кто зайдёт. Если порт виден из
интернета, задайте пароль заранее через `APP_PASSWORD` (см. [настройки](docs/configuration.md#вход-и-пароль)).

Подробно: сборка своего образа, права на папки, обновление, переезд со старого контейнера
автосинка — в [docs/installation.md](docs/installation.md).

## Первая настройка

Всё — во вкладке **«Настройки»**. Обязательного почти ничего нет:

1. **YouTube cookies** — загрузите `cookies.txt`, иначе на объёме YouTube начнёт требовать
   «подтвердите, что вы не робот». [Как получить](docs/sources.md#youtube-и-cookies)
2. **Navidrome** — адрес и админ-пользователь, чтобы новые треки появлялись сразу.
   [Подробнее](docs/sources.md#navidrome)
3. По желанию — источники для треков, которых нет на YouTube:
   [Spotify напрямую](docs/sources.md#spotify-напрямую-librespot) (вход через ваш аккаунт) и
   [Deezer](docs/sources.md#deezer) (ARL-токен).
4. По желанию — [Liked Songs](docs/sources.md#liked-songs): нужно своё приложение Spotify.

Баннер вверху страницы подскажет, если чего-то не хватает.

## Как пользоваться

1. **Плейлисты** → «+ Добавить плейлист»: имя и ссылка на плейлист / альбом / исполнителя
   Spotify (или `saved` для «Любимых треков») → **Sync**. Дальше их обновляет автосинк
   (по умолчанию раз в сутки).
2. **Ненайденные** — треки, которые spotdl не нашёл. «искать на YT ↗» открывает поиск;
   вставьте найденную ссылку и нажмите **Скачать**. Либо сразу **Spotify 320k** /
   **Deezer** — они ищут сами. **Скачать все** применяет выбранный источник ко всему списку.
3. Загрузки идут в фоне: панель **«Задачи»** справа снизу показывает очередь, статусы и логи.
   Скачанный трек сам попадает в m3u-плейлист и исчезает из списка ненайденных.
4. **Апгрейд 320k** — старт/стоп фоновой замены библиотеки на 320k, прогресс и ETA.

## Риски

Скачивание через librespot («Spotify 320k», апгрейд) и с Deezer нарушает условия этих сервисов:
**аккаунт могут заблокировать**, особенно при массовых загрузках. Безопасный режим, паузы и
лимит в сутки снижают риск, но не убирают его. Используйте для личной библиотеки и на свой риск.
