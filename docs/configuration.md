## Как устроены настройки

Почти всё меняется во вкладке **«Настройки»** — compose можно оставить минимальным. Любую
настройку можно задать и переменной окружения в compose. Кто кого главнее:

- **Обычные настройки** (автосинк, битрейт, паузы, лимиты…): значение из env — это значение
  **по умолчанию**, а UI его переопределяет. В UI у поля видно, откуда умолчание; «↺ сбросить»
  убирает переопределение. Изменения действуют сразу, без рестарта.
  Если значение поменяли в UI, правка той же переменной в compose уже ни на что не влияет, пока
  не нажать «сбросить», — выберите одно место для настроек.
- **Пароль и секреты** (Deezer ARL, Spotify-приложение, Navidrome): наоборот, **env важнее UI**.
  Заданное в compose из браузера не поменять — поле заблокировано. Так заданный администратором
  секрет нельзя подменить через UI.
- **Системные** (пути, uid, шаблон имён) — только env, в UI видны для справки.

## Вход и пароль

| Переменная | По умолчанию | Что делает |
|-----------|--------------|------------|
| `AUTH_ENABLED` | `true` | `false` — вход без пароля. **Только если порт не виден из интернета.** Из UI не отключается — намеренно. |
| `APP_PASSWORD` | — | Пароль. Старое имя `APP_AUTH_TOKEN` тоже работает. Если задан — важнее UI, сменить можно только в compose. |

Если `APP_PASSWORD` не задан, при первом открытии сервис попросит **придумать пароль** — на
сервере хранится только его хэш (`/conf/.webui-auth.json`). Сменить: «Настройки» → «Доступ».
Пока пароль не задан, его может задать первый, кто откроет UI, — если порт смотрит в интернет,
задайте `APP_PASSWORD` заранее.

- Браузер хранит не пароль, а токен сессии (срок — настройка «Срок жизни входа», 30 дней).
- Смена пароля (в UI или в compose) разлогинивает все устройства.
- После 5 неверных паролей с одного IP вход блокируется на 10 минут.
- **Забыли пароль**, заданный в UI, — удалите `/conf/.webui-auth.json`, сервис попросит задать
  новый. Заданный в compose — смотрите там.

## Настройки из UI

Группы совпадают с карточками во вкладке «Настройки». В колонке «Env» — имя переменной, если
хотите задать умолчание в compose.

### Автосинк

| Настройка | Env | По умолчанию | Описание |
|-----------|-----|--------------|----------|
| Интервал автосинка | `AUTOSYNC_INTERVAL_HOURS` | `24` ч | Синк всех плейлистов по расписанию. `0` — выключить. |
| Автосинк после старта контейнера | `AUTOSYNC_ON_START` | вкл | Один синк вскоре после запуска (если автосинк включён). |
| Задержка автосинка после старта | `AUTOSYNC_START_DELAY` | `20` с | Чтобы веб успел подняться. |

### YouTube (spotdl)

| Настройка | Env | По умолчанию | Описание |
|-----------|-----|--------------|----------|
| Битрейт mp3 с YouTube | `YOUTUBE_BITRATE` | `auto` | `auto` — как у источника (YouTube отдаёт ~128–160k), или `128k`…`320k`. |
| Где искать аудио | `AUDIO_PROVIDERS` | `youtube-music` | `youtube-music`, `youtube` или `youtube-music,youtube` (второй — запасной). |
| Тексты песен | `LYRICS_PROVIDERS` | `genius,azlyrics,musixmatch` | Обычные; `synced,musixmatch,genius` — синхронизированные, иначе обычные; `off` — не искать. |
| Файлы .lrc рядом с треками | `GENERATE_LRC` | выкл | Синхронизированный текст отдельным файлом — Navidrome его показывает. |
| Если файл уже скачан | `OVERWRITE` | `skip` | `skip` — пропустить, `metadata` — обновить теги, `force` — перекачать. |

### Загрузка

| Настройка | Env | По умолчанию | Описание |
|-----------|-----|--------------|----------|
| Параллельных загрузок spotdl | `SPOTDL_THREADS` | `2` | На каждую загрузку — свой ffmpeg. Больше — быстрее, но выше нагрузка на CPU. |
| Битрейт mp3 (заливка, Deezer, Spotify) | `UPLOAD_BITRATE` | `320k` | Для YouTube — отдельная настройка выше. |
| Таймаут на один трек | `DOWNLOAD_TRACK_TIMEOUT` | `3600` с | Зависшую загрузку убьёт сторож. Real-time качается со скоростью прослушивания — не ставьте меньше длины длинных треков. `0` — без таймаута. |

### Spotify (librespot)

| Настройка | Env | По умолчанию | Описание |
|-----------|-----|--------------|----------|
| Качество Spotify | `ZOTIFY_QUALITY` | `very_high` | `very_high` — 320k (нужен Premium), `high` — 160k, `normal` — 96k. |
| Безопасный режим | `ZOTIFY_SAFE_MODE` | вкл | Одиночные «Spotify 320k» — в real-time (скорость прослушивания, анти-бан). Массовые загрузки и апгрейд — всегда real-time. Тумблер есть и в шапке. |
| Пауза между треками: от / до | `ZOTIFY_BULK_WAIT_MIN` / `ZOTIFY_BULK_WAIT_MAX` | `5` / `15` с | Случайная пауза поверх real-time при массовых загрузках. `0` — без паузы. |

### Апгрейд 320k

| Настройка | Env | По умолчанию | Описание |
|-----------|-----|--------------|----------|
| Не апгрейдить файлы от | `UPGRADE_MIN_BITRATE` | `300` kbps | Файлы с таким битрейтом и выше считаются уже хорошими. |
| Лимит апгрейда в сутки | `UPGRADE_PER_DAY` | `0` | Анти-бан. `0` — без лимита. |
| Таймаут апгрейда на трек | `UPGRADE_TRACK_TIMEOUT` | `1200` с | Потом воркер перезапускается. |

### Сервис

| Настройка | Env | По умолчанию | Описание |
|-----------|-----|--------------|----------|
| Хранить завершённых задач | `JOBS_HISTORY` | `400` | Старые вытесняются. Больше — больше памяти. |
| Строк лога у завершённой задачи | `FINISHED_LOG_LINES` | `300` | Полный вывод всегда есть в `docker logs`. |
| Срок жизни входа | `SESSION_TTL_DAYS` | `30` дн | Действует на новые входы. |

### Отдельные карточки

Эти настраиваются своими карточками во вкладке «Настройки», подробности — в
[источниках и интеграциях](sources.md):

- **Navidrome** — адрес, админ-пользователь, пароль, «сканировать автоматически», «не чаще раза в N минут» (15).
- **YouTube cookies** — загрузка `cookies.txt`.
- **Deezer** — ARL-токен.
- **Spotify напрямую** — вход для «Spotify 320k» и апгрейда.
- **Spotify-приложение** — для Liked Songs.

## Секреты

Обычно вводятся в UI. Env, если задан, важнее UI.

| Env | Что это | Где хранится при вводе из UI |
|-----|---------|------------------------------|
| `DEEZER_ARL` | ARL-токен Deezer | `/conf/deezer_arl.txt` |
| `SPOTIFY_CLIENT_ID` / `SPOTIFY_CLIENT_SECRET` | своё приложение Spotify для Liked Songs | `/conf/spotify_app.json` |
| `NAVIDROME_URL` / `NAVIDROME_USER` / `NAVIDROME_PASSWORD` | подключение к Navidrome | `/conf/navidrome.json` |
| `ZOTIFY_USERNAME` / `ZOTIFY_PASSWORD` | логин/пароль Spotify для librespot — только для аккаунтов с паролем (не Facebook/Google) | — (обычно вход через UI → `/conf/zotify_credentials.json`) |

Файлы секретов создаются с правами 600, а сами секреты никогда не отдаются обратно в браузер.

## Системные — только env

| Env | По умолчанию | Описание |
|-----|--------------|----------|
| `PUID` / `PGID` | `998` / `100` | uid:gid процесса — как у Navidrome. |
| `WEB_PORT` | `8000` | Порт внутри контейнера. |
| `CONF_DIR` / `MUSIC_DIR` | `/conf` / `/music` | Корни данных и музыки. |
| `OUTPUT_TEMPLATE` | `/music/spotify/{album-artist}/{album}/{track-number} - {title}.{output-ext}` | Шаблон путей spotdl. **Не меняйте на готовой библиотеке** — пути разъедутся, появятся дубли. |
| `AUDIO_FORMAT` | `mp3` | Формат библиотеки. То же предупреждение. |
| `M3U_EXT` | `m3u8` | Расширение плейлистов. |

Пути к отдельным файлам (`ZOTIFY_CREDENTIALS_FILE`, `SPOTIFY_USER_TOKEN_FILE`, `COOKIE_FILE`,
`PLAYLISTS_FILE`, …) тоже переопределяются env, но менять их обычно незачем.

## Файлы в /conf

Всё состояние сервиса — в `/conf`. Для бэкапа достаточно этой папки.

| Файл | Что это |
|------|---------|
| `playlists.txt` | список плейлистов, строки `Имя\|ссылка` |
| `<id>.spotdl` | состояние синка каждого плейлиста (spotdl) |
| `errors/<имя>.txt` | ненайденные треки по плейлистам |
| `cookies.txt` | YouTube cookies |
| `deezer_arl.txt` | Deezer ARL |
| `zotify_credentials.json` | креды librespot («Spotify напрямую») |
| `spotify_app.json`, `.spotify-user-token.json` | приложение Spotify и вход для Liked Songs |
| `navidrome.json` | подключение к Navidrome |
| `.webui-settings.json` | настройки, изменённые в UI |
| `.webui-auth.json` | хэш пароля и ключ сессий (удалить = задать пароль заново) |
| `.webui-upgraded.json` | какие треки уже апгрейжены до 320k |
| `.webui-locks/`, `.webui-uploads/` | служебное: локи синка, временные файлы загрузок |
